# Obtain the source data

The [World Bank K-LSRH Wave 1 access page](https://microdata.worldbank.org/catalog/6409/get-microdata) provides the data without a purchase: create a free account, describe the research and accept the public-use conditions. Download `KEN_2022_K-LSRH_v01_M_STATA14.zip` and extract `hhm.dta` to `raw/release/hhm.dta`.

The household roster is sufficient for this analysis. The separately restricted child-respondent module is not required. Review the terms for your own use; do not redistribute microdata or attempt identification. This directory is ignored except for this README. The published tables and figures contain aggregate results only. [Source citation and input hash](../docs/methodology.md).
