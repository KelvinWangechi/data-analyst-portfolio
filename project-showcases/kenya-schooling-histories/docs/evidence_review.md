# Sources and their analytical use

| Source | Evidence used | Analytical consequence |
|---|---|---|
| [K-LSRH Wave 1 catalog](https://microdata.worldbank.org/catalog/6409) | Household roster, sampling frame and household weights | Use roster members and household weights; interpret supported samples rather than national prevalence |
| Released `hhm.dta` metadata and records | Schooling value labels, nine actual-location strata, batch, weights and respondent status | Verify codes directly, reconcile classifications and quantify discrepancies |
| [Questionnaire](https://microdata.worldbank.org/catalog/6409/download/180509), p. 32 | Q15 ever attendance; Q17 current/planned enrolment; Q18–20 attendance, holidays and return plans | Distinguish system membership from attendance on interview day; specify the exit sensitivity |
| Questionnaire, pp. 35–36 | Routing for children’s non-attendance reasons | Do not treat these responses as representative explanations for all never-attenders |
| [World Bank report](https://microdata.worldbank.org/catalog/6409/download/180510), pp. 23–25, Figures 21–24 | Existing primary-age enrolment and never-attendance analysis; curriculum-specific age definition | Acknowledge prior findings; do not substitute published percentages for the fixed-age calculation |

The report is *Building Evidence to Enhance the Welfare of Refugees and Host Communities* (World Bank, 2024). This project’s estimates come from the downloaded roster, not values read from its charts or the catalog’s unweighted frequency pages. Later-wave reports and subsequent policy implementation are outside this analysis.
